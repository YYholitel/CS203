## 时间复杂度和空间复杂度

|           | Static Array | Dynamic Array |     |
| --------- | ------------ | ------------- | --- |
| Search    | O(n)         | O(n)          |     |
| Access    | O(1)         | O(1)          |     |
| Insertion | N/A          | O(n)          |     |
| Appending | N/A          | O(1)          |     |
| Deletion  | N/A          | O(n)          |     |
- 获取都是O（1）
- 动态数组的插入和删除都是O（n)
-  动态数组的添加（在尾部）是O(1)
